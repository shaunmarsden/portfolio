01 / EVIDENCE RECORD

Reliable Automation Lab

The original experiment ran three repetitions per design: 216 episodes across the same 24 authored scenarios. Later hardening added five actual child-process crash windows and 200 seeded recovery traces. The project has 47 automated tests.

The manual baseline is a simulation, with assumed effort. It also achieved 60/66 correct single postings and 6/6 recoveries. Five eligible records remained missing in both careful designs; corruption remained explicitly reported. These are local fictional systems, not distributed production infrastructure. Engineering cost, operator time and business ROI are unmeasured.

02 / EVIDENCE RECORD

Model Evaluation Lab

The authorised 21 October evaluation made 144 calls over 48 authored cases, not 144 independent examples. Two false escalations also occurred. The later guard-repair holdout improved 15/30 to 30/30, with critical misses 5 → 0 and false escalations 10 → 0. It was agent-authored, not independently labelled. The full lab has 119 automated tests.

The scorer checks routing, schema and allowed source IDs, not free-text truth. Historical deterministic replay still has nine routing errors; the combined saved-model guard/source replay has 13. The 24-response AI-assisted critique is not independent validation. Original raw replies and review mappings remain private. No fresh model-control effectiveness, usability or review-time result is claimed.

03 / EVIDENCE RECORD

Human-Approved Service Request Workflow

The saved walkthrough covered six requests, six decisions, two actions and 14 audit events. Another 18 mock-recovery commands challenged rollback and the external-side-effect/local-commit window. Tests cover unauthorised actions, self-approval, duplicate commands, changed content and stale versions.

All review decisions were scripted fixtures. Role selection is not authentication, the audit is locally editable, and callbacks hold a SQLite write transaction. Monitoring can be lost when the store is unavailable or locked. A genuine reference passage does not authorise an access grant or queue change. Real external actions were mocked only.

What is public, what stays private

This site contains newly written case-study summaries, selected independently generated code and fictional tests, and declared aggregate results. The service test includes a short attributed public-domain NIST reference fixture. It does not include employer material, customer records, confidential chats, private review packs or raw model output.

The historical measurements are retained as dated observations. Original run data are privately retained, so public readers cannot independently re-score all 144 model replies or inspect every historical command. The review kit is a deliberate subset: it does not reproduce the later guard holdout, historical model responses or original performance timings.
