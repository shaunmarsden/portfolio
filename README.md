# Shaun Marsden: independent AI and automation portfolio

[Visit the portfolio](https://shaunmarsden.github.io/portfolio/) for three
Codex-assisted independent exercises:

- [Reliable Automation Lab](https://shaunmarsden.github.io/portfolio/reliable-automation.html):
  controlled local transfer, failure recovery and a simulated manual comparator.
- [Model Evaluation Lab](https://shaunmarsden.github.io/portfolio/model-evaluation.html):
  repeated historical model evaluation, critical misses and deterministic controls.
- [Human-Approved Service Request Workflow](https://shaunmarsden.github.io/portfolio/human-approved-workflow.html):
  validated requests, approval boundaries and mocked side-effect recovery.

The [evidence page](https://shaunmarsden.github.io/portfolio/evidence.html) separates
my documented contribution, Codex-operated work, automated testing and the absence
of independent human validation. The projects use fictional inputs and permitted
public references. They do not establish production delivery, personal proficiency
certification, customers or measured employer ROI.

The downloadable review kit contains selected source and fictional test fixtures,
not original model replies, private review packs or production credentials. Its
included README documents the 88 offline checks. The full historical evaluation
cannot be independently re-scored from this public subset.

This repository hosts only the public portfolio. Contact details remain
placeholders. The review-kit tests run offline without paid models. Pages publishes the
approved default branch. No reuse licence has been selected here.
